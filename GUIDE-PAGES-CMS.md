# Modifier le site SERILEC avec Pages CMS

## Connexion

1. Aller sur https://app.pagescms.org/
2. Cliquer sur **Sign in with GitHub**.
3. Autoriser Pages CMS à accéder au dépôt `laszlogulyas77-cpu/site-internet`.
4. Ouvrir le dépôt `site-internet`.

La configuration est stockée dans le fichier `.pages.yml` à la racine du dépôt.

## Rubriques disponibles

### Réglages et textes principaux
Permet de modifier :
- l'email ;
- le téléphone ;
- l'adresse ;
- les titres et introductions des pages ;
- les principaux textes de la page d'accueil ;
- le texte du pied de page.

### Compétences
Chaque compétence contient :
- un numéro ;
- une catégorie ;
- un titre ;
- une description ;
- une liste de prestations ;
- un interrupteur pour afficher ou masquer la compétence.

### Projets réalisés
Chaque projet contient :
- le nom du projet ;
- la catégorie ;
- le lieu ;
- une description ;
- une photo ;
- une option pour l'afficher sur la page d'accueil ;
- une option pour le publier ou le masquer.

### Partenaires
Chaque partenaire contient :
- son nom ;
- sa catégorie ;
- une description ;
- un logo facultatif ;
- une option pour le publier ou le masquer.

### Actualités
Chaque actualité contient :
- un titre ;
- une catégorie ;
- une date ;
- un résumé ;
- une image ;
- un lien facultatif ;
- une option de mise à la une ;
- une option de publication.

## Publication

Pages CMS enregistre directement les modifications dans GitHub. Le site est ensuite remis à jour automatiquement par GitHub Pages lorsque celui-ci est activé.

## Bonnes pratiques pour les photos

- Format recommandé : WebP ou JPG.
- Largeur conseillée : 1 600 à 2 000 pixels.
- Éviter les fichiers supérieurs à 2 Mo.
- Donner aux fichiers des noms explicites sans accents : `hotel-ampere-lobby.webp`.
- Toujours renseigner la description de l'image pour l'accessibilité et le référencement.

## Modifications de design

Pages CMS sert à modifier les contenus. Pour changer la mise en page, les couleurs, les animations ou la structure du site, modifier les fichiers HTML, CSS et JavaScript du dépôt ou demander la modification dans ChatGPT via la connexion GitHub.
